Co-occurrence correlation (Pearson r) between user feedback tags

How to Read this Matrix

Each cell calculates the Pearson correlation coefficient (r) between two design feedback tags based on how often they co-occur in the same user submissions.

Positive Correlation (+0.05 to +1.00): Colored blue. Suggests the tags are frequently selected together on the same dashboards (e.g., related design qualities).
Negative Correlation (-0.05 to -1.00): Colored red. Suggests the tags are mutually exclusive or rarely appear together on the same layouts (e.g., contrasting attributes).
Zero/Weak Correlation (-0.05 to +0.05): Neutral light gray/gray. Indicates no linear relationship (co-occurrence is random or there are zero occurrences). Hover over any cell to see the exact correlation score.
